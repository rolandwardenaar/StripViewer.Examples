# StripViewer Pro - Moderne Voertuig Onderdelen Applicatie

## 🚗 Overzicht

StripViewer Pro is een moderne, gebruiksvriendelijke webapplicatie voor het zoeken van voertuigonderdelen op basis van kentekens. De applicatie is volledig vernieuwd met een professioneel design en verbeterde gebruikerservaring.

## ✨ Nieuwe Features & Verbeteringen

### 🎨 Modern Design
- **Elegant kleurenschema** met gradient achtergronden
- **Glasmorfisme effecten** met transparante kaarten en blur effecten
- **Responsive design** dat perfect werkt op alle apparaten
- **Hover animaties** voor betere interactie feedback
- **Font Awesome iconen** voor duidelijke visuele communicatie

### 🔍 Verbeterde Gebruikerservaring
- **Intuïtieve navigatie** met duidelijke stappen
- **Auto-formattering** van kenteken invoer
- **Realtime validatie** van formulieren
- **Loading states** voor betere feedback
- **Sticky sidebar** voor geselecteerde artikelen
- **Breadcrumb-achtige flow** door verschillende secties

### 📱 Responsive & Toegankelijk
- **Mobile-first design** voor optimale mobiele ervaring
- **Toetsenbord navigatie** ondersteuning
- **Screen reader vriendelijk** met proper ARIA labels
- **Dark mode ondersteuning** voor oogcomfort
- **Print-vriendelijke** layouts

### 🛠 Technische Verbeteringen
- **Bootstrap 5** voor moderne UI componenten
- **CSS Grid & Flexbox** voor flexibele layouts
- **CSS Custom Properties** voor consistente theming
- **Performance optimalisaties** met CSS transforms
- **Cross-browser compatibiliteit**

## 📝 Gebruikersinstructies

1. **Start de applicatie** en voer een geldig kenteken in
2. **Bekijk voertuiginformatie** na succesvolle zoekopdracht
3. **Selecteer onderdeel categorie** uit de dropdown
4. **Kies specifiek onderdeel** uit de lijst
5. **Gebruik de StripViewer** om onderdelen te bekijken
6. **Geef feedback** via het moderne feedback formulier
